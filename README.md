# ReflexArena# ReflexArena

A full-stack browser-based reaction time game where players compete for the highest score.

## Overview

ReflexArena is a browser game that challenges players to react as quickly as possible by clicking randomly appearing targets within a fixed time limit. Scores are submitted to a backend API, stored in a database, and displayed on a live leaderboard.

## Features

- Reaction-based gameplay
- Live leaderboard
- RESTful API
- Persistent score storage
- Responsive interface
- Clean architecture
